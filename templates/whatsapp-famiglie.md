# Template comunicazione WhatsApp / famiglie

> Breve: si legge sul telefono in 10 secondi. Compila SOLO con dati presenti nel brief. Se manca qualcosa, chiedi.

```
*[Titolo evento]* 🍂

[1-2 frasi: cosa, per chi. Diamo del tu / "voi" se scriviamo a tutti.]

📅 [giorno, data]
🕒 [ora]
📍 [luogo]

[Se serve: cosa portare / come confermare / chi contattare — SOLO se indicato nel brief]

[1 hashtag max] 
```

Regole:
- Massimo ~60 parole.
- Una sola azione richiesta, chiara.
- Allega la locandina (immagine o PDF).
- Niente nomi di bambini né dati personali.
